# Secure Password Generator 🔐

A lightweight, client-side web application that generates secure, random passwords based on user-defined criteria. This project highlights DOM manipulation, event-driven programming, and string randomization techniques using Vanilla JavaScript.

## Live Demo
You can test the application live here: https://drkabak.github.io/Password-Generator/

## Features
* **Customizable Criteria:** Generate passwords using a mix of uppercase letters, lowercase letters, numbers, and symbols.
* **Length Control:** Adjustable password length to meet various security requirements.
* **One-Click Copy:** Seamless clipboard integration (`navigator.clipboard`) to instantly copy the generated password.
* **Client-Side Security:** All generation processes happen directly in the browser without server interaction.

## Tech Stack
* **Frontend:** HTML5, CSS3
* **Logic:** Vanilla JavaScript (ES6+)
